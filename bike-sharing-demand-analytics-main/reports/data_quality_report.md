## Decisions

- Raw files are never modified; the cleaned/feature table is written separately to `data/processed/hour_features.csv`.
- No rows are removed. Statistical outliers are flagged only, because extreme demand (or near-zero demand during storms) is real behaviour, not bad data.
- Missing hourly timestamps are documented, not imputed. Model training uses only observed hours; daily commuting totals in the hypothesis test are computed over observed hours and re-checked using only days with complete commuting windows.
- `casual` and `registered` are excluded from all predictors of `cnt` (they sum to the target).
- `instant` is a row index and is never used as a feature.
- Season labels follow the official README coding, with the calendar caveat documented above.
